⚠️ نکته بسیار مهم: حل مشکل باز نشدن سایت‌ها در مرورگر (DNS over SOCKS5)

علت خطای Destination IP Prohibited در لاگ‌ها این است که مرورگر شما دامنه‌ها را روی شبکه داخلی ایران Resolve می‌کند و سپس آی‌پی فیلترشده/ایرانی را به ساکس ارسال می‌کند که موزیلا آن را مسدود می‌کند.

راه حل قطعی: باید گزینه Remote DNS را در کلاینت یا مرورگر خود روشن کنید:

  • مرورگر فایرفاکس (Firefox): در Settings ➔ Network Settings ➔ فعال‌سازی گزینه Proxy DNS when using SOCKS v5
  • اکستنشن SwitchyOmega (کروم/اج): انتخاب نوع پروتکل SOCKS5 (نه SOCKS4) که به طور پیش‌فرض DNS را از طریق ساکس عبور می‌دهد.
  • اپ تلگرام: به طور پیش‌فرض دامنه‌ها را از سمت سرور حل می‌کند و به همین دلیل بدون مشکل کار می‌کند.
  • تست در ترمینال: همیشه از فلگ socks5h:// (با حرف h) استفاده کنید تا DNS هم پروکسی شود: curl -x socks5h://192.168.1.1:1080 https://google.com
